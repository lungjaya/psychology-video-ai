# Panduan Produksi (dari HP)

## Alur

1. Claude (skill ini) → paket produksi
2. AI image generator → 1 gambar per scene (pakai prompt gambar)
3. AI image-to-video → 1 klip per scene, 3–7 detik (pakai prompt animasi)
4. Voice-over → rekam sendiri atau text-to-speech
5. CapCut → susun, subtitle, musik, SFX, ekspor

## Tips konsistensi karakter

- Buat dulu 1 gambar "karakter referensi" yang paling bagus. Simpan.
- Jika tool mendukung *image reference / character reference*, selalu unggah gambar itu.
- Generate 2–4 variasi per scene, pilih yang paling mirip dengan referensi.

## Langkah CapCut

1. New project → rasio 9:16
2. Impor klip scene 1 sampai terakhir sesuai urutan
3. Audio → impor voice-over (atau Text-to-speech dari naskah VOICE-OVER)
4. Potong/geser klip supaya pas dengan kalimat voice-over
5. Text → Auto captions, lalu rapikan memakai bagian SUBTITLE
6. Tambahkan teks besar per scene (bagian TEKS DI LAYAR) di area atas
7. Musik latar: volume 10–20%, ambient/piano lembut
8. SFX ringan: whoosh di transisi, ambience ruangan, heartbeat untuk momen tegang
9. Transisi: cross-dissolve atau cut biasa; hindari efek berlebihan
10. Ekspor 1080×1920, 30 fps, MP4

## Spesifikasi akhir

- 1080 × 1920, 9:16, MP4
- 20–60 detik (ideal 30–40)
- Subtitle aman dari area tombol aplikasi (jangan terlalu bawah/kanan)

## Platform

TikTok, Instagram Reels, YouTube Shorts, Threads. Caption sama, hashtag disesuaikan.
